## 1. Navegación en la ventana principal

| Tecla | Acción | Dónde |
|---|---|---|
| **Alt+1** | Llevar el foco al árbol de navegación (cuentas y categorías) | Ventana principal |
| **Alt+2** | Llevar el foco a la lista de chats | Ventana principal |
| **Intro** | Abrir la conversación del chat enfocado | Lista de chats |
| **F5** | Actualizar la lista de chats desde el servidor | Lista de chats |
| **Ctrl+M** | Marcar chat como leído / no leído | Lista de chats |
| **Ctrl+B** | Fijar o desfijar el chat de la parte superior | Lista de chats |
| **Supr** | Salir del grupo/canal o borrar conversación (con confirmación) | Lista de chats |
| **Ctrl+Tab** | Cambiar a la siguiente cuenta de Telegram conectada | Ventana principal |
| **Ctrl+Mayús+Tab** | Cambiar a la cuenta de Telegram anterior | Ventana principal |
| **Ctrl+Mayús+B** | Leer en voz alta el contenido de la barra de estado | Ventana principal |
| **Tecla Aplicaciones** o **Mayús+F10** | Menú contextual con todas las acciones sobre el chat (abrir, fijar, archivar, silenciar, carpetas, **llamar por audio**, **videollamada**...) | Lista de chats |

## 2. En la conversación de un chat

| Tecla | Acción | Dónde |
|---|---|---|
| **Intro** o **Ctrl+Intro** | Enviar el mensaje escrito en el cuadro de edición | Cuadro de texto |
| **Tab** | Avanzar desde el cuadro de texto hacia los botones de acción (Enviar, Adjuntar, Nota de voz, Llamada, etc.) | Cuadro de texto |
| **Shift+Tab** | Retroceder desde el cuadro de texto al historial de mensajes | Cuadro de texto |
| **Escape** | Devolver el foco al listado de mensajes (o cerrar conversación si está en mensajes) | Conversación |
| **Ctrl+Shift+J** | Abrir selector para insertar fragmentos de texto o plantillas guardadas | Cuadro de texto |
| **Espacio** | Reproducir / pausar notas de voz, audios y vídeos | Lista de mensajes |
| **Espacio** | Si el mensaje contiene botones interactivos de bot, abrir diálogo con la lista accesible de botones | Lista de mensajes |
| **Ctrl+Espacio** | Marcar o desmarcar el mensaje enfocado para compartirlo en lote | Lista de mensajes |
| **Ctrl+Mayús+C** | Abrir el diálogo para compartir los mensajes marcados (o el enfocado) con otros chats | Lista de mensajes |
| **Ctrl+T** | Traducir el texto del mensaje al español | Lista de mensajes |
| **Ctrl+I** | Describir con Inteligencia Artificial la imagen del mensaje | Lista de mensajes |
| **Ctrl+C** | Copiar el texto del mensaje al portapapeles | Lista de mensajes |
| **Intro** | Abrir el enlace web incluido en el mensaje (si hay varios, permite elegir) | Lista de mensajes |
| **Tecla Aplicaciones** o **Mayús+F10** | Menú del mensaje: responder, fijar, reaccionar, editar, borrar, ver detalles, adjuntos... | Lista de mensajes |

## 3. Llamadas, Videollamadas y Grabación

| Tecla | Acción | Dónde |
|---|---|---|
| **Alt+L** | Iniciar llamada de audio o entrar al chat de voz | Conversación / Menú contextual |
| **Alt+V** | Iniciar videollamada | Conversación / Menú contextual |
| **Alt+S** | Silenciar o reactivar el micrófono | Ventana de llamada activa |
| **Alt+C** | Encender o apagar la cámara de vídeo | Ventana de llamada activa |
| **Alt+G** | Iniciar o detener la grabación de la llamada (guarda en MP3 en `data\grabaciones\`) | Ventana de llamada activa |
| **Alt+D** | Abrir selector de dispositivos de audio y cámara web | Ventana de llamada activa |
| **Escape** o **Alt+X** | Colgar la llamada activa y guardar grabación en curso | Ventana de llamada activa |
| **Intro** | Responder llamada entrante con audio | Diálogo de llamada entrante |
| **Alt+V** | Responder llamada entrante activando vídeo | Diálogo de llamada entrante |
| **Escape** | Rechazar llamada entrante | Diálogo de llamada entrante |

## 4. Telegram Drive (Nube personal)

| Tecla | Acción | Dónde |
|---|---|---|
| **Intro** | Abrir carpeta enfocada o descargar el archivo enfocado | Lista de la nube |
| **Retroceso** | Subir a la carpeta contenedora anterior | Lista de la nube |
| **Alt+Izquierda** | Ir hacia atrás en el historial de navegación | Lista de la nube |
| **Alt+Derecha** | Ir hacia adelante en el historial de navegación | Lista de la nube |
| **F5** o **Ctrl+Mayús+R** | Actualizar la lista de archivos y carpetas | Lista de la nube |
| **Ctrl+Mayús+N** | Crear una nueva carpeta | Lista de la nube |
| **Ctrl+U** | Subir archivos a la nube | Lista de la nube |
| **Ctrl+Mayús+U** | Subir una carpeta completa manteniendo su estructura interna | Lista de la nube |
| **Ctrl+D** | Descargar los elementos seleccionados | Lista de la nube |
| **Ctrl+F** | Buscar archivos o carpetas por nombre | Lista de la nube |
| **Ctrl+F2** | Cambiar el nombre del elemento enfocado | Lista de la nube |
| **Supr** | Enviar el elemento enfocado a la papelera | Lista de la nube |
| **Mayús+Supr** | Eliminar definitivamente el elemento de la nube | Lista de la nube |
| **Espacio** | Marcar / desmarcar elemento para operar sobre varios a la vez | Lista de la nube |
| **Ctrl+A** | Seleccionar todos los elementos | Lista de la nube |
| **Ctrl+X** / **Ctrl+C** / **Ctrl+V** | Cortar / Copiar / Pegar elementos entre carpetas | Lista de la nube |
| **Alt+Intro** | Ver propiedades del archivo o carpeta | Lista de la nube |
| **Ctrl+Mayús+B** | Leer la barra de estado de Telegram Drive (transferencias, espacio, elementos) | Ventana de la nube |
| **Escape** | Cerrar Telegram Drive | Ventana de la nube |

## 5. Controles del reproductor de audio

Disponibles globalmente mientras suena un audio o nota de voz:

| Tecla | Acción |
|---|---|
| **F1** | Retroceder en la reproducción |
| **F2** | Reproducir o pausar |
| **F3** | Avanzar en la reproducción |
| **F4** | Detener reproducción |
| **F7** | Reducir la velocidad de reproducción |
| **F8** | Aumentar la velocidad de reproducción |
| **F9** | Bajar el volumen |
| **F10** | Subir el volumen |

| **Ctrl+Shift+U** | Abrir Telegram Drive |

| **Alt+F4** | Salir de la aplicación |
