# TelegramAccess

**Cliente de Telegram accesible para Windows (MTProto / Kurigram)**  
Diseñado al 100 % para el manejo completo por teclado y optimizado para lectores de pantalla (**NVDA**, **JAWS** y **Narrador de Windows**).

## Novedades e Implementaciones de TelegramAccess

- **Llamadas de voz y videollamadas nativas:** Soporte completo tanto para llamadas privadas 1 a 1 como para grupos/canales mediante `pytgcalls` y `ntgcalls`.
- **Grabación integrada de llamadas (Alt+G):** Grabación directa de audio y vídeo de la conversación en formato MP3 con almacenamiento en `data\grabaciones\`.
- **Selector accesible de dispositivos (Alt+D):** Elección interactiva de micrófonos y cámaras web sin interferencias con lectores de pantalla.
- **Telegram Drive:** Almacenamiento ilimitado en tu nube personal segura.
- **Sistema de actualización automática integrada:** Comprobación e instalación desde GitHub Releases (`joseonce/TelegramAccess`) con sonido de espera acústico continuo (`updating.wav`) durante la descarga y copia de archivos hasta que la nueva versión arranca.
